# QuoteCompare v0.1 验证记录

日期：2026-10-07。环境：Apple Silicon，macOS 15.7.4，Python 3.14.3，Electron 38.8.6，React 19，SQLite。

本次实现保留一个 Python 服务、四个业务模块、六张表、25 项接口。sqlite3 直接事务处理，jsonschema 复用 OpenAPI，不增加 ORM、重复 DTO、消息队列或独立服务。

验证命令：`python -m pytest backend/tests -q` **21 passed**；`npm run test:reads`、`test:e2e`、`test:coverage`（25场景）、`test:recovery`、生产构建 **全部通过**。新增读取检查先在旧代码失败，再在重构代码通过。测试有一条已有的 Starlette/httpx 弃用提示，不影响执行结果。

仍为一个服务、四个业务模块、六张表、25项接口。生产源文件行数1956→1965（增加9行），主要来自密钥显式分支和历史列表直接组装；本轮实际减少的是重复查询、数据往返和状态包装，保留可读性。

## 验证边界

模型测试服务为测试专用的独立 HTTP 服务，覆盖真正的客户端请求/响应解析。生产应用没有模拟模型回退，始终调用当前服务商。未使用用户真实 API Key，真实账号模型可用性、自然语言提取质量、账单扣费未实测。用户仍需要核对 AI 结果。三家测试响应来自受控 HTTP 服务，因此不能证明真实服务商账户可用、余额正确或实际扣费。

文件选择/保存测试替换了系统对话框的选择结果，随后实际执行 IPC、文件读取和写入；没有自动点击系统对话框。官方账单入口测试验证了调用参数，没有验证外部浏览器登录账单页。日期/单位核对测试不代表任意自然语言日期和单位都能自动归一化。

当前安装包验证了 ARM64 Mac；Intel 构建工作流已提供但未在此机器执行。应用未做 Developer ID 签名或 Apple 公证，属于本地开发包；正式分发需要配置证书。没有“全新另一台 Mac”实机测试，本次系统 PATH 安装包测试验证了它不使用本机开发 Python 环境。

DeepSeek 存在高峰/低峰及中国法定节假日规则；本应用显示官方档位，未核验实际档位时费用保留未知。OpenAI/Claude 总账户余额并非本应用调用汇总，首版只提供官方账单入口。
